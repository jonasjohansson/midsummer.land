# midsummer.land

Static invitation site for **Midsummerland 2026: The Arcana** — 19 to 21 June 2026, Vibäck 10, Nyköping.

Vanilla HTML/CSS/JS. No build step. Deploys to https://midsummer.land/ via GitHub Pages on push to `main`.

## Local preview

```sh
python3 -m http.server 3000
# or
npx serve -l 3000
```

Then visit http://localhost:3000/.
